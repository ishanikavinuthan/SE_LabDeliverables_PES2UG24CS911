# Lab 4 – Vibe Coding: Number Guessing Repair Lab

## Project Description

Number Guessing Repair Lab is an interactive number-guessing game developed using Python and Pygame. Players guess a randomly generated number between 1 and 100 using hints provided by the game.

## Deliverables

- Python and Pygame source code
- Repaired and updated gameplay implementation
- Dynamic range hints and guess history
- Project README and requirements
